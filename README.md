# Projeto-POO

# Gerenciador de Contratos

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos (POO).

## Descrição

Sistema em Python para cadastro e acompanhamento de contratos. Permite registrar
contratos vinculados a clientes, calcular reajustes, verificar prazos de vencimento
e gerar alertas para contratos próximos do fim da vigência.

## Funcionalidades

- Cadastro de clientes e contratos
- Cálculo de reajuste de valores
- Verificação de contratos próximos ao vencimento
- Geração de alertas
- Relatório resumido dos contratos ativos

## Tecnologias

- Python 3
